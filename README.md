# 📷 WebCamObscura

## ❓ What is this?
WebCamObscura is a OpenCV Video Capture application that allows you 
to record video both from your webcam and microphone, and video capture devices. 
It is designed to be simple to use while providing powerful features for video processing using FFmpeg.

## Features
- Capture video from webcam and microphone
- Record video from video capture devices
- Real-time video processing using OpenCV
- Save recorded videos in various formats using FFmpeg
- Windows-only application (This is made with Dear ImGui with Win32 and DirectX 11 backends)
